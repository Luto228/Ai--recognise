### 🌟 О проекте (About)

**AI Recognizer** — это ультимативное Chrome-расширение для охоты на ИИ-контент. В мире, где дипфейки становятся неотличимы от реальности, наш бот — ваш персональный цифровой детектив. 

Проект сочетает в себе мощь новейших моделей **Google Gemini** и стильный, интерактивный интерфейс, который встраивается прямо в ваш браузер.

---

### 🎮 Основные фишки (Key Features)

*   🤖 **Интерактивный Ассистент**: Плавающая кнопка-бот, которую можно перетаскивать по экрану. Она умеет прятаться за край экрана и оставлять "ручку" для быстрого вызова.
*   👀 **Режим Инспектора**: 
    *   **Один клик** по боту — и вы в режиме поиска. 
    *   Просто наведите на любую картинку, она подсветится. 
    *   **Клик по картинке** — и бот мгновенно отправляет её на анализ.
*   📊 **Личный Профиль и История**:
    *   **Двойной клик** по боту открывает ваш профиль.
    *   Следите за статистикой: **"УБИТО ИИ"** (найденные фейки) vs **"ИЗУЧЕНО ЛЮДСКОГО"** (реальные фото).
    *   Просматривайте историю проверок в стильной галерее.
*   💾 **Умное Сохранение**: Возможность скачивать проверенные изображения с кастомным именем прямо из интерфейса бота.
*   🌐 **Локализация**: Полная поддержка **Русского** и **Английского** языков.
*   🛡️ **Система Авторизации**: Личный аккаунт для синхронизации вашей истории и достижений.
*   🧠 **Мощный Бэкенд**: Использует передовые модели Gemini (3.1 Flash Lite) для глубокого анализа пикселей и артефактов.

---

### 🛠️ Технический стек (Tech Stack)

*   **Extension**: JavaScript (ES6+), HTML5, Vanilla CSS (Glassmorphism, Animations).
*   **Backend**: Python 3.10+, Flask, Flask-CORS.
*   **Database**: SQLite3 (хранение пользователей и истории).
*   **AI Engine**: Google GenAI SDK (Gemini API).

### 🚀 Быстрый старт (Setup)

#### 1. Настройка Бэкенда (Python)
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте файл `.env` в корне проекта и добавьте ваш ключ:
   ```env
   GEMINI_TOKEN="ВАШ_API_КЛЮЧ_ЗДЕСЬ"
   ```
3. Запустите сервер:
   ```bash
   python Main.py
   ```
   *Сервер будет доступен на `http://127.0.0.1:5000`*

#### 2. Установка Расширения
1. Перейдите в `chrome://extensions/`.
2. Включите **"Режим разработчика"** (Developer mode).
3. Нажмите **"Загрузить распакованное расширение"** (Load unpacked) и выберите папку проекта.
4. Авторизуйтесь через интерфейс бота и начинайте охоту!
