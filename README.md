### 🌟 О проекте (About the Project)

**AI Recognizer** — это мощное Chrome-расширение, созданное для того, чтобы мгновенно вычислять сгенерированные изображения в сети. 

В эпоху, когда нейросети штампуют подделки, неотличимые от реальности, наш бот предоставляет простой и изящный способ докопаться до истины прямо в браузере, не отрываясь от просмотра контента.

---

### 🎨 Как это работает (How it Works)

Расширение встраивается на любую веб-страницу и предоставляет интуитивный интерфейс:

1. **Плавающая кнопка**: На экране всегда доступен аккуратный виджет бота (🤖).
2. **Контекстное меню**: Вы можете нажать правой кнопкой мыши по любой картинке и выбрать "Recognise AI".
3. **Режим инспектора ("Выделяй, я смотрю! 👀")**: 
   - Кликните один раз по кнопке-боту.
   - Наведите курсор на любую подозрительную картинку на сайте (она выделится).
   - Кликните по картинке, и бот отправит её на анализ!
4. **Вердикт**: Мощный ИИ (Google Gemini) анализирует пиксели и артефакты, выдавая результат в стильном всплывающем окне: **"Это ИИ"** или **"Это Реальность"** вместе с уверенностью (%) и пояснением.
5. **Статистика бота**: Сделайте двойной клик по кнопке, чтобы открыть профиль. Там вы найдете свою историю проверок: сколько фейков выявил бот ("УБИТО ИИ") и сколько реальных фото проверил ("ИЗУЧЕНО ЛЮДСКОГО"), с возможностью скачать сохраненные картинки.

---

### 🚀 Основные возможности (Features)

- ✨ **Интерактивный UI на любом сайте**: Встроенный оверлей, стильные модальные окна, режим инспектора (Inspect Mode).
- 🖼️ **Мгновенный анализ по клику**: Больше не нужно скачивать картинки и загружать их на сторонние сайты.
- 📊 **Система статистики**: Бот запоминает проверенные вами изображения (сохраняется в локальное хранилище браузера).
- 🧠 **Продвинутый движок**: Использует современные модели Google Gemini (gemini-2.5-flash / gemini-2.0-flash) через локальный Flask-сервер.

---

### 🛠️ Технологический стек (Tech Stack)

- **Frontend / Extension**: HTML5, Vanilla CSS (Glassmorphism UI), JavaScript (Chrome Extension API).
- **Backend**: Python (Flask).
- **AI Logic**: Google GenAI SDK (Gemini API).

### 📦 Установка и запуск (Setup)

Проект состоит из двух частей: локального сервера (Backend) и самого браузерного расширения.

#### 1. Настройка Backend-сервера (Python)
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Luto228/Ai--recognise.git
   cd Ai--recognise
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Настройте API-ключ Gemini:
   Создайте в корне проекта файл `.env` (если его нет) и добавьте свой токен от Google Gemini API:
   ```env
   GEMINI_TOKEN="ВАШ_API_КЛЮЧ_ЗДЕСЬ"
   ```
4. Запустите сервер:
   ```bash
   python Main.py
   ```
   *(Сервер запустится на http://127.0.0.1:5000)*

#### 2. Установка Chrome-расширения
1. Откройте браузер Chrome и перейдите на страницу расширений: `chrome://extensions/`.
2. В правом верхнем углу включите переключатель **«Режим разработчика»** (Developer mode).
3. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) в левом верхнем углу.
4. Выберите папку с проектом `Ai--recognise`.
5. Готово! Расширение установлено. Зайдите на любой сайт и найдите плавающего бота 🤖.
